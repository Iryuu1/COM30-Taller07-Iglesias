# COM30 Taller 07 · Inventario de equipos

Aplicación desarrollada con Angular 22 para el Taller 07 de Programación con Frameworks para Web. El trabajo aplica formularios reactivos, RxJS y signals a la consulta de un inventario de equipos.

## Requisitos

- Node.js y npm

## Instalación y ejecución

```bash
npm install
npx ng serve --open
```

La aplicación se abre en `http://localhost:4200/`.

## Compilación

```bash
npx ng build
```

## Tecnologías

- Angular 22 con componentes standalone
- Formularios reactivos de Angular
- RxJS para el flujo de búsqueda
- Signals y `computed` para el estado de la interfaz
